## 2. 目标与输入输出契约

### 2.1 两个输出必须分开

1. **训练侧接触关系估计** C：解释某个时刻物体表面与左/右夹指哪一部分可能接触，可利用该训练视频的前后观测。它是未校准的模型关系估计，附带不确定性。
2. **部署侧偏好评分** S：给定当前单物体 RGB-D/点云和当前夹爪位姿、朝向、开度，输出当前可观察物体各点的偏好评分及不确定范围。高分表示示范中获得较多可信接触支持的倾向，**不等于此刻已经接触、抓取成功率或精确接触概率**。

抓取、推、转动、拉动只是可能发生的交互；不设动作类别作为接触开关。只有两根夹指的内侧、外侧、侧面、指尖与物体之间的接触计入目标。掌部、腕部、机械臂、物体与桌面/篮筐/其他物体接触均不计入目标，后者只能作为环境解释。

### 2.2 字段权限

| 字段 | 训练观测/辅助任务 | 当前帧评分推理 |
|---|---|---|
| 主相机与腕相机 RGB-D、K、逐帧 camera_to_world | 可用完整合法训练视频 | 仅当前帧；双相机缺失情况须显式标记 |
| 当前真实物体点、法向及来源/有效性 | 可用 | 可用，采样不能读未来或模型接触目标 |
| 实际夹指几何、关节状态、手位姿、开度 | 可用时间序列 | 当前值及其确定性几何变换 |
| actions | 对齐后供动作条件辅助学习 | 首版偏好头不需要动作或未来动作 |

官方示范文件一般供策略训练，官方评估主要是环境 rollout；不能虚构官方自带一个 400/50/50 的接触预测划分。为同时满足“全量训练覆盖”和“留出案例展示”，本方案采用以下**新方案专属、自定义 episode 划分**：

|---|---|---:|---:|
| train | 0–39 | 40 | 400 |
| development | 45–49 | 5 | 50 |

这里“全量训练”是全部 10 个任务、全部 400 段 train、全部合法时刻进入索引；不再仅选旧 10 个接触证据通过事件。**不能声称 500 段全部参与了训练。** 若以后要求全部 500 段训练，必须另设不重叠的测试来源；这属于协议变化，不能一边训练同一视频、一边称其独立测试。

## 4. 数据接口与真实表面：自动处理，不制作接触标签

### 4.1 时间、坐标与双相机

默认使用 agentview 和 robot0_eye_in_hand 两台相机；后者在原 HDF5 中通常对应 eye_in_hand_rgb。此前新增三个固定相机不进入本轮默认输入。

已有局部实测为“回放帧 t 对应官方 obs[t−1]，t0 未知”，这是旧案例结论，实施时必须对 400/50 段分别核查，不直接套用。需要锁定：

- RGB、派生 depth、K、相机位姿、手位姿、开度及 action 的逐帧索引表；
- ee 原点与 hand/指尖原点的固定几何偏移；ee_ori 的旋转表示通过正运动学核对，不默认是欧拉角；
- 世界、相机、手和物体局部坐标的方向/单位；默认米、弧度；
- action[t] 的作用区间与实际观测变化，不把目标动作等同于实际末端运动，更不等同于接触力；
- 时间步采用已核实的回放时钟。若只能确认模拟 20 Hz/0.05 s，应称模拟时长，不冒称真实机器人实测时钟。

真实表面点必须保存 episode、frame、camera、pixel、depth 与标定版本。双视角重复观测同一表面不当作两倍接触时长。原 RGB 与派生深度未对齐时，同一批次只能使用重新渲染并已验证对齐的 RGB-D 对，不混拼。

### 4.2 对象提议与遮挡表面记忆

- 输入接口仍是上游选定单物体；全量示范处理时用冻结的自动分割/跟踪提议产生对象候选，不按文件名、文字或仿真 segmentation 选择目标。
- 第一版候选接口采用官方 SAM2.1 自动掩膜提议与视频传播，加双视角真实深度和冻结 CoTracker3 的可见对应。仅作为对象/表面观测工具，不产生接触答案。所有候选都参与关系评估；身份冲突保持多个假设或未知。
- 每个查询的对象提议只读该时刻及允许的历史；当前帧评分输入的 mask/点云不能借用训练教师未来分割结果。推理要求仅当前输入时，采用当前帧自动提议或上游当前物体 mask。
- 双相机观测保留来源和置信；不要求两台同时看见才保留点。把单相机缺测变成缺测标记，不把整帧接触清零。
- 对完整训练视频建立表面记忆。接触前、接触后真实见过的表面可以被时序模型重新定位；配准仅使用观测一致性，不以“必须贴住夹指”来调整表面。
- 完全未观测表面只允许预测分布/未知，不加入“真实点”集合。当前学生输入仍只采样当前真实点；隐藏表面的训练教师记忆不泄漏到当前输入。
- 自动分割、可见对应和重建误差只控制观测可信度，不等价于接触正/负。不能复用“初帧深度一致”作为唯一物体前景定义。

工具权重按官方可获得版本锁定；SAM2/CoTracker 含外部监督，不称全流程纯无监督。若依赖不可用，登记接口修订，不默默换模型。

## 5. LCJP-Object v0.1 网络规格

### 5.1 网络结构与作用

| 模块 | 初版规格 | 输入/输出及作用 |
|---|---|---|
| 图像特征 | 冻结 DINOv3 ViT-S/16；384→128 线性投影 | 两视角 RGB patch 特征投影到真实点；解决局部外观表征，不直接判接触 |
| 物体点编码器 | PointNet++ SA 512/128/32，FP 回到最多 2048 点；输出 128 维 | 输入米制 XYZ、法向/有效性、RGB 特征、测量质量；保留局部形状 |
| 夹指编码器 | 两根夹指各 64 个确定性表面节点；MLP→128 | 节点覆盖全部实际夹指表面，按实测关节运动学更新；排除掌部 |
| 当前交互编码器 | 2 层 cross-attention，宽 256、4 头 | 物体点与夹指节点交互；加入相对位置、法向、方向和开度 |
| 时序关系模块 | 16 帧窗口；4 层 Transformer，宽 256、8 头、dropout 0.1 | 训练侧累积可见/遮挡证据；整段以重叠窗口与表面记忆处理 |
| 局部关系头 | MLP 256→128→关系参数 | 独立输出物体表面—夹指关系强度、切向滑动状态、几何不确定性；不是 attention 权重 |
| 共享运动层 | 每个刚体/活动部件一个 SE(3) 增量，3 次可微阻尼最小二乘迭代 | 用局部关系解释整物体运动；不让每个点各自决定是否随手移动 |
| 观测解码头 | 点位/深度、masked feature、重投影 | 自监督目标来自实际观测，不需要接触标签 |
| 当前偏好头 | 逐点 MLP 256→128→64→3 | 输出偏好中心及上下范围/不确定性，只读当前交互表示 |
| EMA 副本 | 训练新模块参数的 EMA，衰减 0.99 | 生成较平稳在线目标；不是单独训练出来的接触教师 |

输入 N<2048 时保留全部真实点并 padding mask，不复制点改变权重。采样仅基于当前 XYZ；保留米制尺度与夹爪几何，禁止把每个对象独立缩成单位球后丢掉真实大小。

DINOv3 输入可按官方接口上采样至 256，但原始 128 像素信息量不增加。若采用不同分辨率回放，必须在执行前登记并对全部 split 统一；不能专门提高测试案例画质。

### 5.2 接触潜变量的语义

对物体表面 i、夹指表面节点 j、时刻 t，定义 C(i,j,t)∈[0,1]。另设“无夹指作用/环境解释”和“证据不足”状态；关系头不是每点 softmax 强迫选一根夹指。

可以用每个物体点最近 8 个夹指节点减少计算，但即使远离也保留几何距离，邻接仅是计算图，不是“距离小就接触”的标签。节点稀疏仅用于网络；几何距离计算仍使用完整已知夹指表面/网格。

不能采用如下错误结构：

- 每点 gate 高就预测该点随手运动：整个刚体未接触的背面也随物体运动，会产生“全物体接触”；
- gate × 任意增益/自由神经力：二者可互相缩放，gate 没有稳定的接触含义；
- 从 attention 图直接读接触：关注物体不等于物理接触。

本模型的 C 只控制局部物体—夹指约束；这些约束通过共享 SE(3) 解释所有真实表面点的运动。位置必须同时由真实表面与夹指几何约束。

### 5.3 受限运动解释器

对一个物体/活动部件估计运动 ξ：

~~~text
ξ* = argminξ [
  E_history(ξ)
  + E_environment(ξ)
  + Σij C(i,j,t) E_finger(T(ξ)p_i, finger_j)
]
~~~

- E_history：由近期物体运动提供静止/近恒速度解释；不能读取未来夹指运动。
- E_environment：由可观测背景/支撑与物体运动提供环境解释。它不计入目标接触，也不允许用大容量自由残差吞掉所有预测误差。
- E_finger：夹指表面的法向间隙、相对法向运动，以及可学习的黏着/滑动切向约束。不是“永远刚性随手”的假设。
- 使用显式几何残差与固定单位尺度，不附加任意可学习增益；误差尺度来自训练观测误差，范围受约束。
- 仅从历史输入和夹指观测预测被留出的物体观测；**留出点/未来目标不能进入同一次最小二乘拟合**。
- 双向整段关系解释可使用未来，必须单独标为离线训练教师；不能将它的重建误差称为因果预测性能。
- 不读取物体仿真姿态、不把 action 当力、不宣称估出了真实接触力。
- 静止且完全遮挡时，多种关系可能同样解释观测；此时输出宽范围/未知，不能用结构设计宣称已解决可辨识性。

LIBERO-Object 首版主要拟合刚体。抽屉/开关后续须显式区分活动部件与静止主体；架构接口保留部件槽位，但本轮没有这些任务训练证据。

## 6. 没有接触标签时，具体用什么损失

### 6.1 观测监督与梯度来源

| 损失 | 实际目标来自哪里 | 更新什么 | 要解决的问题 |
|---|---|---|---|
| L_motion | 未参与拟合的真实 RGB-D 对应点/短期位移 | 点编码、关系头、运动层 | 接触解释能否解释观测后果 |
| L_depth | 独立留出相机/时刻的深度与重投影 | 表面定位、关系模块 | 防止只拟合同一视角的附近点 |
| L_mask | 随机隐藏但真实可见的表面位置/冻结视觉特征 | 表面记忆、时序模块 | 学习遮挡期间的定位与不确定性 |
| L_gap / L_pen | 已知夹指几何与真实表面的连续间隙/穿透残差 | 局部关系与表面分布 | 防止隔空作用、表面穿透；不生成硬正例 |
| L_complexity | 按表面面积归一化的无必要关系复杂度 | 关系头 | 防止全物体高关系；不规定正点数量 |
| L_consistency | 同一真实来源在双视角/不同遮挡子集的估计 | 关系与表面模块 | 防止依赖某个视角或点数捷径 |
| L_score | EMA 在线关系时长目标，stop-gradient | 当前偏好头及当前编码 | 学习示范接触偏好，未来仅作训练目标 |

示例连续几何项：

~~~text
L_gap = average_area[ C(i,j,t) · robust(d(i,j,t) / σ(i,j,t)) ]
L_pen = average_area[ max(0, -signed_distance / σ)² ]
~~~

σ 是训练观测的深度/配准误差尺度，不是接触概率。不能让模型无限增大 σ 来逃避错误；首版用训练内留出重建残差估计固定基准，预测不确定性限制为基准的 0.5–4 倍，并保留似然的 log σ 项。该范围是待检验的数值建模超参数，不是接触标签门槛。

只用 L_gap 会全零关系；只用运动重建会产生伪相关；因此需要受限结构、联合损失和第 10 节的退化检查。不能通过“每帧必须有若干接触点”修补全零结果。

### 6.2 损失权重与训练规则

初版将损失按单位/有效来源数归一化为三组：

~~~text
L_observation = L_motion + L_depth + 0.1 L_mask
L_physical = L_gap + L_pen + 0.01 L_complexity
L_joint = L_observation + 0.1 L_physical + 0.1 L_consistency + L_score
~~~

这些数值是首版工程超参数，**不是经数据证明的最优权重，也不是“没有任何人为假设”**。不靠用户区间设权重，不在测试后改权重。先记录各组实际量级/梯度；若量纲、数值导致失衡，在看测试前写本文修订并用训练/开发无标签损失核查。不给每个任务单独调一组阈值。

关系分支的梯度来自观测重建和几何结构；偏好分支不反向把在线目标推成容易拟合的答案。对 EMA 目标 stop-gradient，EMA 无独立 optimizer。共享当前编码仍接受偏好梯度；每次记录梯度量级并保留仅观测分支对照，不能说停止目标梯度就已彻底避免自举退化。

### 6.3 未知如何产生与处理

未知不由低分直接定义，也不由网络低熵直接排除。综合实际来源缺失、跨视角/时间块留出分歧、测量误差扰动及不同可行运动解释，形成 C 的敏感性包络 [C_low,C_high]。这不是校准概率置信区间。

- 缺失来源或多种解释无法区分时，允许 [0,1]。
- 真正观察到表面分离可通过深度/几何似然提供排除证据，不用“没有检出接触”作负例。
- 目标未知不训练偏好中心为 0；只训练不确定性输出/参与合法观测辅助。
- 不用模型自己的置信分数筛掉所有难帧，然后宣称成功。
- 每个任务同时报告：总帧、有效观测帧、可定位表面、关系不确定量；分母保留全部 episode。

## 7. 时长、多视频和偏好头如何在一次训练中连接

### 7.1 同一真实表面按时间累计

同一 episode 内，用可追溯的真实表面身份 k 聚合双视角和重叠窗口；缺少对应时令该时刻包络为 [0,1]，不凭邻点补零；每个模拟时刻仅计一次，不按像素数/相机数累加：

~~~text
D_low(e,k)  = Σt C_low(e,k,t)  · Δt
D_high(e,k) = Σt C_high(e,k,t) · Δt
g(D,T_e) = 1 - exp(-3D/T_e)
Y(e,k) = [ g(D_low,T_e), g(D_high,T_e) ]
~~~

D_low/D_high 是模型关系分数积分得到的“接触支持持续量范围”，不是传感器测得的真实接触秒数；C 不确定时积分也不确定。T_e 是该完整 episode 已核实的模拟时长，系数 3 是冻结的饱和设计参数；短视频/长视频的影响通过 episode 等权控制，不伪称它是物理常数。必须附带秒数 D 与覆盖率，防止归一化掩盖很短接触。全程未知会得到宽目标范围，而不是高分真值。

一个视频中有多次尝试也只占一个视频权重。若失败尝试真实碰到夹指，可以贡献它实际发生的短接触；不因任务失败一律清零。接触时长长可以提高偏好证据，但不能保证所有短接触都不重要、所有失败都很短。首版不加人工成功/失败筛选。

### 7.2 当前条件与跨视频汇总

- 学生 S(P_q,G_q) 只读查询时刻物体和夹爪；同视频真实表面映射后的 Y 只进入 loss。
- 训练查询覆盖接近、建立接触、运输、分离等整个视频时段，不只选择已判定接触帧；这些名称只用于结果解释，不作为人工切段标签。
- 同一视频的后验在线目标只作该视频已观察交互的证据，不能推导未执行夹爪朝向的反事实正确答案。夹爪条件是否实际有用需要消融验证。
- 多视频之间首先以任务/资产和 episode 等权共享网络参数。**不按点索引、名称或强制标准模板直接平均不同物体表面。**
- 没有可靠跨实例表面对应时，不建“杯子某一点的全类平均标签”；几何特征与共享参数承担迁移，独立新形状测试检验它。
- 颜色、背景及相机丢弃增强可用于抑制捷径；不随意缩放物体而保持夹爪尺寸不变来伪造物理接触目标。

### 7.3 在线目标与评分损失

EMA 在合法完整 train 视频上生成随模型变化的关系/时长区间，缓存仅作加速并带模型版本；初始化目标未知。每个训练 epoch 更新一遍完整 train 目标，所有新模块从第一个有合法梯度的 batch 即处于同一训练作业，无“先把独立接触模型训练合格再启动评分”的阶段。

偏好头输出中心 s 和区间 [l,u]（限制 0≤l≤s≤u≤1）：

- 可辨识目标以 stop-gradient 的区间中心和覆盖权重训练 s；
- l/u 拟合目标包络，另加区间一致性项；
- [0,1] 的目标不对 s 施加高/低分训练，只要求展示未知；
- 训练初期只有观测损失有效时，明确记录评分有效更新数；不能将随机初始评分称学习结果；
- 如果正式训练后仍无可辨识目标、或全零/全高退化，判为“本轮机制失败”，不是通过调显示阈值伪造候选。

一次联合训练仍有自动数据读取、点云构建和目标计算；它们由同一入口调度，不要求用户另做接触标签。用户最终不用为每段新视频再训练接触模块。

## 8. 正式训练计划

### 8.1 固定首版配置

| 项目 | 计划 |
|---|---|
| 训练范围 | 10 任务 × 40 train episode = 400；未按旧接触规则删段 |
| 验证范围 | 10 × 5 development = 50，自动观测损失选 best |
| 首版 seed | 2026；本轮先单 seed 可行性，不伪称统计稳定 |
| 新模块初始化 | 同一 seed 随机初始化；外部冻结权重单列 SHA256 |
| Optimizer | AdamW，学习率 1e-4，weight decay 1e-4，gradient clip 1 |
| 训练预算 | 30 epochs；每 epoch 每 episode 4 个 16 帧窗口，累计 48,000 窗口曝光 |
| 采样 | 任务→episode 等权；四个全视频时间分层内轮换起点，预生成计划 |
| 有效 batch | 8 个不同 episode 的窗口；不足显存仅改梯度累积，保持有效 batch |
| 窗口覆盖 | 执行前验证累计计划覆盖全部合法帧；必要尾窗补齐并登记实际更新数 |
| EMA | 0.99；每 epoch 全 train 的关系目标刷新，不接触 dev/test 更新 |
| 验证频率 | 每 epoch；dev 完整视频的固定留出观测协议 |
| checkpoint | best 与 last，含 optimizer/RNG/sampler/EMA/目标版本；禁止事后凭测试改选 |
| 预期工期 | 在远程工程预检后按实际速度估算，本文件不虚报 GPU 小时 |

正式预算包括在线目标全视频刷新，必须报告它的计算量，不能只报告 optimizer 步数。建议区分“窗口训练次数”和“完整视频前向次数”。

### 8.2 一次入口的执行顺序

1. **协议与依赖冻结**：生成清单、禁读约束、相机/坐标契约、代码/权重哈希；原始示范不修改。
2. **自动观测缓存**：派生双相机深度、当前对象提议、真实点与对应。已有缓存逐项符合契约即可复用，不能复用含接触标签的样本。
3. **训练内工程预检**：固定 2 个 train episode 做 shape、梯度、单步前后向、留出泄漏和 checkpoint 恢复检查；该临时权重丢弃，正式训练统一重置 seed。
4. **完整 train 联合训练**：400 段均参与，观测/关系/偏好同作业更新；不另建接触模型预训练任务。
5. **development 评价与冻结**：按事前无标签准则选 best，保存所有失败与不确定量。
6. **固定一个 held-out 案例**：冻结后才读取、派生、推理、展示；不回到该例调参。
7. **本文写回结果**：准确数量、配置与代码哈希、loss/退化检查、逐任务结果、网页链接、限制及下一步。

工程预检不是把三段视频训练好再冒充全量。用户无需逐条确认正常可逆实现；后续执行遵循已授权范围。当前这次只完成方案文件。

### 8.3 模型选择

开发选择指标采用统一标准化的留出点位/深度负对数似然、重投影误差及 masked feature 误差；权重在训练前锁定。按 episode 先平均、再按 10 任务等权。

不使用人工区间、旧接触伪标签 AP、显示正点数或“哪个测试页面更好看”选择 best。观测误差更低不自动证明接触语义正确；第 10 节的语义/退化检查必须另列。

## 10. 分阶段验收与失败时做什么

| 阶段 | 做什么/交付什么 | 通过条件 | 失败时处理 |
|---|---|---|---|
| P0 方案 | 本文、来源与继承关系、固定划分/测试例 | 用户请求均有模块、数据与验收对应；不冒充已实现 | 在同一 MD 修订 |
| E0 数据契约 | 400/50/50 清单、历史暴露、逐字段权限 | episode 交集为空，禁读有效；全部 train 明确可处理 | 修数据接口，不缩成少数“成功例” |
| E1 观测与坐标 | 双相机来源、时间索引、表面误差 | 回投/跨相机/状态对齐按实际精度通过；未来扰动不改变当前输入 | 修对齐，保留原记录 |
| E2 工程训练 | 模型实现、梯度/恢复与泄漏检查 | 关系头、评分头均有各自合法梯度；无 NaN/无目标泄漏 | 修实现并记录版本，不称模型无效 |
| E3 全量学习 | J1（必要时 A1）全部预算与日志 | 400 段完整参与；观测损失有学习，关系不全零/全高；报告未知 | 若退化，先定位结构/数据原因，不能靠改阈值 |
| E4 冻结展示 | 一个完整 held-out 视频、逐点预测网页 | 同一模型可复算，帧号准确，当前评分无未来；所有帧可看 | 修显示不得改分数；失败结果照实展示 |
| E5 用户复核 | 物体表面/两指关系与实际视频对照 | 用户判断目标区域是否有用，记录缺失/错误 | 只作复核；新优化另记同文档迭代 |

必须单列以下检查：

1. **不把共动当接触**：高关系是否覆盖整个物体背面，还是定位到可解释的夹指邻接表面。
2. **不把环境接触算给夹指**：支撑/篮筐邻近点不能因物体运动骤变自动成为目标。
3. **不因遮挡清零**：真实表面身份稳定时能否保留估计与扩大不确定范围；重现时是否与留出观测一致。
4. **不强行持续**：分离后是否仍靠时长惯性保持高关系；开度变化只是输入，不是固定清零条件。
5. **不靠点量作弊**：改变采样密度但保留几何，关系与面积归一化结果是否稳定。
6. **不掩盖条件失效**：仅物体特征与加入夹爪条件的结果分别报告；无优势就记录，不能人工制造方向答案。
7. **不靠自信当正确**：报告多种可行解释和重建分歧；静态完全遮挡可保持未知。
8. **不报告伪精度**：本轮无独立接触真值，不能编 AP/F1/成功率。可以报告留出几何误差、未知覆盖、条件敏感性与用户复核事实。若对旧自动目标计算一致性，必须另标“旧规则一致性”，不用于 best。

全量数据上报告每任务与每 episode 的观测覆盖、重建误差、关系/未知分布和失败原因；不要只放平均值。多个视频共享物体资产，不能把每帧当独立试验。首轮单 seed 不做强显著性结论。

## 11. 网页交付规范

### 3. 推荐方向：指令确定目标，目标与两指学习关系

- 操作对象是烧烤酱瓶；篮子是放置目的地。
- 在当前抓取接触任务中，只为酱瓶的真实观测点输出目标评分。

- 如果今后动作阶段变成抓篮子，重新解析该阶段操作对象，不能永久写死某资产 ID。

2. 同一实例 ID 跨帧维护；重定位必须核验外观与几何，不静默换物体。
3. 保存 target_mask、target_instance_id、source_camera、source_pixel、source_point_index、visibility、identity_confidence 与 abstain_reason。
4. 真实深度点才进入评分；边界混合像素、深度空洞、遮挡点保留失效原因。不能把补全的背面表面宣称为当前真实观测点。
5. 目标丢失或指代不清时不生成“确定高分”；保留完整帧和失败记录。

这是新增语言监督先验的感知组件。准确表述为“无新增人工接触标签、使用预训练视觉语言分割组件”，不能称整个系统从未使用人工语义标注。已有 DINOv2 特征编码器与 Grounding DINO 是不同组件，前者不会自动理解指令。

### 4. v002 的接触学习假设

目标选择解决评分范围，不能单独解决 v001 退化。候选 v002 需独立登记架构/损失/初始化与协议，原 v001 源代码及结果不覆盖。

第一版先学习“当前目标表面与两指的交互支持”，不要把它直接称为抓取成功概率。当前接触、示范中常用抓取位置、尚未尝试位置的抓取质量是三个不同输出；成功示范中未触及的点不自动等于不适合抓取。若保留示范偏好头，必须另行定义其训练证据和报告，不能从瞬时接触分数直接改名。

候选核心目标：比较“无需夹指作用的解释”与“存在夹指作用的解释”，对少量模式做可微边缘化：
Lmotion = -log[sum_m pi_m * p(观测到的下一段目标运动 | mode_m, 过去目标观测, 两指观测)]。
模式至少有无夹指作用、左指、右指、双指；无夹指作用必须保留。局部候选接触点的权重需按真实表面采样面积处理，不能由点云密度决定接触量。

- 独立运动分支只看过去目标观测，采用受限刚体/惯性模型；允许物体自由运动或环境作用的解释，不强制静止。不能读取未来目标位移作为输入，也不能给它无限容量解释一切。
- 夹指分支通过候选目标点与两指表面间的受限运动约束，解释下一段目标轨迹；共享物体刚体运动，局部接触不能由整个物体同步运动直接复制给所有点。
- 先用少量显式模式边缘化检验似然是否可区分，避免第一步就把饱和的 v001 sigmoid 输出作为唯一软标签来源。
- 两分支对同一观测、同一测量尺度评分；尺度从训练观测校准并锁定，限制模型通过放大方差降低惩罚。
- 几何距离/穿透用于排除不可能接触；正支持来自包含夹指作用后对可观测运动的解释改善。近距离本身不是正接触标签。
- 允许滑动/滚动与粘着的不同约束；第一版若只实现粘着，必须标为该受限模型，不能将不同步直接标为无接触。
- 不强制固定正接触比例，不去掉无接触模式，不按 top80% 产生训练标签，不用人为色差或熵正则制造“看起来有接触”。

当前帧评分头从联合运动证据学习，推理只用当前目标与两指输入。训练允许后续观测作为预测目标，但必须切断它们进入当前评分的输入路径。两个观测解释难以区分时记录证据不足；不要靠模型自身预测反复强化自身结论。此方向是待检验假设，并非已证明能够恢复真实接触。

### 5. 改变“未知”的处理，避免全宽区间成为捷径

将“没有足够证据”作为独立有效性/弃权状态，不再要求当前评分头对未知点回归 [0,1] 的区间端点。可信观测上的运动似然仍须优化，弃权不能用于删除难样本、逃避运动预测损失。

中心交互分数、证据质量、可观测性分开报告。只在有可分辨证据的样本上训练相应评分约束，同时公开有效监督覆盖率、缺失原因和每类模式的贡献。是否给出数值区间、如何估计区间需在小试前预登记；没有校准依据时输出“未知/证据不足”，不称接触概率置信区间。不能把所有点变成已知、压窄区间或调色作为验收条件。

### 6. 最小实验顺序及比较

保留原 400/50/50 分区，不扩展留出访问。预览 bbq_sauce/demo45 已被观看，仅作展示记录，不据其画面调超参数或选择 best。建议小试固定全部 10 个任务的 demo0–1 共 20 段作为训练子集，demo2 共 10 段作为训练分区内的机制检查子集；它们不因此变成新的最终测试集。方法方案、种子、预算、评价方向须在运行前锁定。

| 阶段 | 内容 | 目的与判定 |
|---|---|---|
| P0 目标感知 | 不更新接触模型，先输出目标掩膜/身份/目标点云视频。必要时给 v001 第5轮冻结输出加目标范围，明确标为只改选择范围的对照。 | 验证只选择被操作物体，篮子不被误选；遮挡/丢失/同类歧义如实弃权。不能把范围变干净当作接触改善。 |
| P1 静态可辨识性 | 固定训练片段和候选接触模式，比较独立运动与夹指作用似然、各损失对 c 与 logit 的梯度。 | 若两类解释普遍无法区分，先查观测、时间同步、尺度与模式容量，不开始大规模训练。 |
| P2 短程消融 | A：目标选择+原目标；B：相同目标选择+运动证据混合目标；C：B+限制历史旁路。尽可能相同主干初始化/数据顺序/优化预算。 | 先预登记每臂最多300次更新、2个固定种子2026/2027的诊断预算；这是规划预算，不是承诺300步足够收敛。每50次更新记录分支梯度、似然、监督覆盖和分布。 |
| P3 扩展 | 仅当前序检查支持继续时，登记完整 v002 训练及冻结规则，再使用完整400训练/50开发。 | 不默认又跑30轮；完整预算按短程证据与实测吞吐决定。旧v001综合分数不得直接与新目标量纲混比。 |

P0 的人工目视检查只用于核验目标身份/可视化，不生成接触标签。若需分割 IoU，须有独立目标掩膜标注；没有时不虚报精度，改报双视角几何一致性/轨迹失效率与可见性，并承认这些指标不足以证明语义目标选对。

P2 额外保留以下仅用于诊断的对照：去掉夹指作用；在当前几何近似匹配的训练片段间错配/时间错位夹指运动；固定形状和视觉信息改变指物相对位置；相机单视角与双视角。简单随机错配若同时破坏几何分布，只能检测分布变化，不能当作因果接触证明，也不直接把错配样本标成负接触真值。

验收不以“颜色丰富”“接触均值非零”“方差变大”为准。需要同时观察：
- 任务目标选择与身份稳定，非目标点评分字段为不适用；
- 有运动辨识证据的片段对夹指输入有响应，接触模式的贡献能改变预测解释；真实配对与受控错配比较方向一致；
- 有效接触 logit 梯度不持续数值消失，非接触/未知解释仍能保留；
- 目标评分只依赖协议允许的当前输入，无未来、人工范围、模拟接触真值泄漏；
- 已知/未知覆盖、分数/模式分布、观测误差按任务分别公开，不能靠隐藏失败帧改善；
- 同时报告共同的观测预测误差和消融差异。没有真实接触参考，不报告接触准确率或抓取成功率。

停止扩大条件：目标识别经常不确定/错误且无法保证身份；观测无法区分接触解释；有证据但梯度仍饱和；控制实验显示模型基本不使用夹指；未知覆盖的改善仅来自强行收窄区间。满足任一项就回到相应模块，不靠增加训练轮数掩盖。

### 7. 继承、缓存与展示约束

- v001 已学进度不会丢弃，完整暂停快照仍可用于基线或经用户明确要求恢复。
- 新目标函数属于新 run。不得把 v002 写成“v001无改动续训”，也不默认沿用已经饱和的接触/区间头及其AdamW状态。
- 主试验建议同种子新初始化可训练部分；复用冻结官方权重及与协议匹配的 RGB-D、相机标定、夹指几何等确定性缓存。可另登记迁移旧主干的消融，但需说明来源，不与新初始化主试混合。
- 目标掩膜、目标身份与输入字段变化会改变输入缓存；必须按新分割器/权重/协议 hash 产生独立命名空间，不能直接复用旧全提议缓存或旧 online 目标。与掩膜无关的原始观测可继续复用。
- 默认仍展示目标实例内评分最高80%的真实点；固定五个绝对色段，未知独立灰色。非目标用原始 RGB 上下文，分数字段不适用。完整云、低分、未知、失败帧均保留可查看。
- 记录定位、分割、跟踪、点云和评分各阶段延迟以及端到端 p50/p95，再讨论在线速度。离线同步视频不能等同于实时系统。
- 所有代码、模型、数据和新增记录仅在远程。现阶段没有下载新权重、创建新训练进程或改变 v001 的网络/损失。

### 8. 官方组件依据与方法边界

1. Grounding DINO 官方实现：https://github.com/IDEA-Research/GroundingDINO —— 文本条件开放目标检测，可作本地目标定位组件。
2. Grounded-SAM-2 官方集成：https://github.com/IDEA-Research/Grounded-SAM-2 —— 已有定位、分割及视频跟踪串联；默认例子首帧定位，连续ID示例明确仍存在不稳定性，不能直接把示例当可靠身份系统。
3. SAM2 官方实现：https://github.com/facebookresearch/sam2 —— 提供 SAM2.1 权重与图像/视频提示分割；复用现有 tiny 以减少环境变更，文本语义由前端定位模块提供。

上列公开组件支持“可实现的目标感知前端”，并不证明无接触监督的接触分数已可学好。仅有 RGB-D/运动时，静止夹持与近距离未接触、遮挡面上的不同接触点、环境力造成的运动可能存在多种解释。v002 必须先验证在现有观测下能学到什么；如证据不足应报告范围限制。当前建议是继续研究无接触标签路线，但不继续原样运行 v001。
