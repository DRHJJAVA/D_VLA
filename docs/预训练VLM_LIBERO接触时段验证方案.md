## 1. 研究问题和期望交付

问题：别人预训练好的视频VLM，在不更新参数、不添加人工接触训练标签的情况下，能否从一段LIBERO示范中找到夹爪手指与物体的全部接触时段？加入官方任务指令，以及深度／实测状态／动作后，哪些漏检或边界问题改善，哪些反而受指令或动作意图误导？

用户接口拟为一个LIBERO示范路径及episode ID；程序提取该示范的可用观测与原始任务指令，不要求用户逐字段准备。输出是按物体／可见运动部件组织的接触区间、边界不确定范围、判断依据和未知原因，支持同一视频多物体、多次短触及持续接触。

这是完整视频离线分析，允许看整个视频的前后文。它不宣称在线控制、任意RGB视频均可靠或已完成接触表面提取。VLM自己报出的置信数字不视作校准概率，也不套CF014的0.8分数门槛。

## 2. 固定模型与推理方式

首轮只用官方 Qwen/Qwen3-VL-8B-Instruct，全部权重冻结，BF16，无LoRA、梯度更新或自行预训练。选它是可直接部署的视频／多图／文字接口基线，不预设它是最佳模型。TimeLens作为以后可另登记的时间定位对照，本轮不混用多个模型挑最好结果。

真正执行前锁定官方checkpoint revision、权重SHA256、processor／tokenizer、依赖版本、代码和提示词。当前没有这些本轮下载后的hash，不编造。使用独立远程推理环境，避免升级旧D_VLA训练环境。已有服务器GPU为约96GiB RTX PRO 6000 Blackwell；这是设备信息，不是本轮显存占用保证。

推理固定do_sample=false、seed2026、max_new_tokens=2048；不取多次采样中的最好答案。输出过长则按相同固定时间窗拆分四组，不静默截断事件。确定性解码也不声称跨硬件逐位一致。本轮无训练损失、学习率或更新轮次。

## 3. LIBERO可用输入：选择理由与形式

| 输入 | 是否作为新模型输入 | 如何使用与保留限制 |
| --- | --- | --- |
| 主相机、腕相机RGB | 四组必需 | 每帧同时提供双视角、相机名、原帧号／时刻；不在物体上叠满点 |
| 官方任务自然语言指令 | 有指令的组 | 只读原任务元数据；说明意图，不当作“接触已发生”的事实；不补入人工时段／动作分段 |
| 相机内外参、机器人夹指几何 | 传感器组的准备输入 | 用于投影、坐标转换与机器人自身像素排除；不是场景物体真值 |
| 深度 | 传感器组 | 用已有独立回放RGB-D及有效性，计算有单位的局部三维观测／可见间隔；原始深度保存供追溯，不把伪彩色图称为VLM原生深度理解 |
| ee_pos／ee_ori、gripper_states | 传感器组 | 实测手位姿、两指状态、由已知几何求实际开度及相邻位姿变化；明确坐标系、单位、有效标志 |
| joint_states | 准备与核查 | 可用于机器人投影／FK核查，默认不把整条冗余关节序列塞进提示词 |
| actions | 传感器组 | 时间对齐的原始控制量与经控制器定义核实的含义；命令不是实际运动／接触证据 |
| 从RGB-D估计的物体局部运动 | 首轮不额外引入 | 避免同时增加运动估计器及其误差；保留真实机器人运动测量。以后若单独加入，按部件、可见性和质量报告，不强制全场景单刚体 |
| 奖励、success／done、仿真contact、场景物体精确姿态／分割ID | 不提供给判别器 | 这些可直接泄露答案或把任务完成混成接触；旧约束继续保留 |
| CF模型分数、旧held标签、旧自动接触目标、人工区间 | 不提供给VLM及输入选择 | 只在所有新预测固定后，按允许语义做复核 |

完整仿真states如果原回放工具需要，只用于读取官方状态生成RGB-D；不解包场景物体状态作为VLM输入。任务指令进入本VLM方案是用户明确允许的变化；独立自监督／弱监督方案历史的无文本输入保持原状。

**传感器信息如何交给普通VLM：** 首轮不新增一个需要训练的深度／点云编码器。将少量、时间对齐的测量转为附单位表格，例如frame_id、有效标志、实测开度mm、相对片段起点的手位移mm、相邻旋转变化deg、动作控制量、局部可见表面到夹指工作面的距离分位数与覆盖状态。源数据保存米和完整姿态，显示值不作为精确测量真值。

首轮测量表固定为每个实际输入帧的：状态valid、开度、相对窗口首个有效状态的手位移xyz、相邻手旋转角、原action向量及其核实后的含义、双相机各自的观测覆盖状态和可见间隔。相机间不先把测量平均成一个接触分数。局部可见间隔采用已有机器人几何，按各夹指工作面分别计算当前非机器人观测到该面的最近距离及距离分布；限定为手坐标中工作面轴向投影内的观测。只有射线视线可达而非被手指／其他前景遮住的测量才报告，缺失写null；所有数值只作为观测，不设接触距离阈值。该局部投影只是一个有缺口的辅助测量，不限制VLM能发现的接触位置；侧面／指尖接触仍由完整画面判断。准确工作面几何、机器人像素排除与深度有效性沿用已核对的标定接口，执行前锁定到具体源码及字段，接口核查失败则不编造该测量。

局部几何只报告“可见非机器人表面”的测量，可能来自邻物、桌面或另一部件；没有可靠对象归属时明确写unassigned。遮挡时距离填null，不能把没有点写成很远。接近、共动、夹爪闭合和指令执行都不给自动contact标签。不用固定抬升／开度／共动／连续帧门槛删掉任何时段。

## 4. 时间、动作和坐标先检查

- 当前项目已有回放约定：RGB-D帧t对应官方obs运动t−1，t0手状态未知。对每种实际字段核对，不能把RGB、动作和所有状态不加区分统一平移一帧。
- 保存raw_obs_index、render_frame_index、timestamp、action_index及各字段valid。动作到底对应前一状态到后一状态还是其他时序，以实际回放器／控制器为准；未核实字段先缺省，不猜。
- 20Hz只用于已确认控制频率的现有示范；一般通过实际元数据／时间戳映射帧，不用播放器估秒。原始帧号统一0起始、区间含两端，页面明确显示。
- ee_ori表示、轴方向、左右指符号、动作归一化和控制器尺度在执行前登记；不把无量纲action当毫米或把关节值直接当两指净间距。
- hand→world、camera→world明确方向，逆变换采用数值一致实现。核查像素深度重投影及可见机器人投影。相机或状态失配时保留原视频可评估，传感器输入写缺失，记录该案例不是完整模态配对。
- 所有准备步骤遍历完整时间轴，不按接触预测、人工范围或旧成功门槛裁剪。

## 7. 全视频覆盖与帧级细查

预定三个推理层次，全部不训练：

1. **全局层**：整段视频按2fps均匀取帧，额外保留首末帧，双视角。模型输出整体对象对应和可能区间，允许空结果。全局层的文字结论不作为后续窗口的答案提示；它单独保存供比较。
2. **全时间轴检查层**：固定4秒窗口、2秒步长、10fps，末窗补齐到视频结尾。每个窗口独立看双视角和相应组的指令／测量，所有窗口都执行，即使全局层没有发现候选也不跳过。保留重叠段分歧，不自动平滑成接触。
3. **边界细查层**：先冻结四组全时间轴输出，用四组所有接触／分离转换和分歧位置的并集，加前后各0.5秒，生成四组共享细查窗口；有人工范围不参与窗口生成。按原20fps连续帧读取，若实际fps不是20则用实际原帧。长并集窗口切成最多2秒、重叠0.5秒，保证每组查看同样画面。四组初始结果单独保留，明确细查窗用了其他组提出的位置；跨组借候选后的结果不是“独立单遍”表现。

对任何始终判无接触的案例，仍完成第2层，不只查已有候选。若短接触落在10fps抽帧之间，首轮仍可能漏掉，须作为限制报告，不能称逐个原帧都已读。

主四组使用448×448每视角的相同RGB源，保存processor实际尺寸和原帧号映射；原20Hz数据不通过插帧制造证据。局部放大仅在细查中使用：用同一冻结VLM的无任务文字视觉定位先生成夹爪及相邻物体框，框作为共同准备产物，四组共享；该定位不输出接触标签，不读状态／人工范围。定位不可靠就保留全景并标记缺失，不用模型猜的点伪造物理测量。放大保留原像素来源，不声称提高原始分辨率。

若上下文或显存不够，先核实错误，再在本文件登记统一缩短窗口并重生成四组相同清单；不能只给某组降帧率／图像尺寸。全部原始响应和实际输入索引保留，不能只保存整理后的答案。

## 8. 固定提示词语义与输出格式

提示词公共核心拟为：
> 观察这段机器人视频，列出夹爪手指与物体实际接触的所有时间范围。触碰、推压、滑动、夹住和持续保持均属于接触；物体不运动、没有抬升或任务失败不代表没有接触。任务指令描述意图，动作是控制命令，不能据此补想未观察到的接触。对每个判断引用实际提供的帧号；看不清或证据冲突时保留未知。区分直接可见的接触和结合前后帧推断的接触。若不能确定开始／结束，给出可能范围，不凭空报精确帧。只分析实际画面，不按标准操作流程填时间。

B／D追加原指令；C／D追加有单位测量表及缺测说明。详细prompt、系统说明、局部定位提示和JSON schema在第一次执行前完整锁定；不把人给的正确范围当few-shot示例，也不使用旧模型预测做提示。

机器输出字段：
- episode_id、对象／部件短ID、可见外观描述及依据帧；
- contact_intervals：start_frame、end_frame，可为null；start_possible_range和end_possible_range保留不确定边界；
- per_window_spans：每窗按时间排序、互不重叠且覆盖该窗的contact／separation／unknown片段；每片段含起止帧／可能边界及对象ID，不能把“窗口内曾接触”扩成整个窗口接触；
- evidence_mode：direct_visual／temporal_inference／mixed／insufficient；
- evidence_frame_ids、引用测量字段、occlusion、conflict、unknown_reason；
- 原模型文本、解析状态、模型／输入／提示hash。

“判接触”和“证据可见性”是两个字段，遮挡不会自动变成无接触。VLM所报直接可见也只是模型的判断，仍可错误。不用自然语言自报0.9生成概率曲线。页面显示状态带、可能边界带和证据帧。

同层重叠窗口对同一对象的明确接触／分离判断若矛盾，汇总为conflict／unknown；明确判断与未知重叠时保留该判断并标注其他窗口未确认，不把未知当反证。细查仅在实际检查的窗口内更新结果，完整保留初判和改判依据；细查仍冲突则未知。未提供的原帧不能标成direct_visual，区间内插只能明确标为temporal_inference。仅相邻、同物体、无矛盾的接触判断可合并显示；未知间隔保留，不能用闭合状态或平滑算法自动填正。短暂触碰不因不足5帧被删除。解析失败不变成“无接触”；只允许一次不新增语义信息的格式纠正请求并留存两次原文，再失败则标为不可解析。

## 9. 复核与结果判定

人工范围只在全部四组原始输出、解析结果和后处理配置冻结后载入，不用于训练、提示词、选样、窗口选择、阈值或模型选择。

现有正范围只能支持“范围内接触覆盖”检查。对于早期也可能有接触的tomato3，98–160不自动成为整段唯一接触或真实首次起点。没有重新确认完整边界时，不计算声称真实起止误差的指标。tomato3 49–74历史失败范围不再计无接触误报。

本轮逐episode报告：
- 已确认正范围内的接触覆盖、未知占比、被判分离占比，三者共同展示；direct与inferred分别列出；
- white_yellow_mug_demo_5明确未接触44–52内的接触报告率／未知率；
- 已确认持续接触内的断裂次数和最长未被报告的跨度；未知断裂与明确分离分别统计；
- 所有视频的候选事件数、对象归属冲突、完整候选区间、未知区间和解析失败；
- 全局层、固定窗层、细查层分别结果及推理耗时／峰值显存／读取帧数；
- 新三任务没有完整人工真值，仅展示完整视频供查看，不伪造准确率、召回率或全视频F1。
