# D_VLA：RGB-D 物体抓取区域学习与泛化实验方案

版本：v2.0｜日期：2026-10-23｜状态：设计完成，尚未按本方案实施或验收。
来源：原 v1 方案、4k/16k 试跑审计及用户最新要求；规划方法：academic-research-suite / experiment-agent（plan）。本文的结构、规模和阈值是预先规定的实验起点，不是已获得结果。

## 1. 目标与本次修改

从完整成功示范及对应深度中学习：**物体哪些表面经常被夹持，以及不同抓法分别覆盖哪些区域**。面对已见物体的新视角，或颜色、半径、高度、形状改变的同类新实例，输出带分数的物体表面点云。

| 项目 | v2 定义 |
|---|---|
| 训练资料 | 完整示范 RGB-D、相机参数、动作/仿真状态、物体及夹爪几何 |
| 预测输入 | 当前两路 RGB-D、相机参数、已知夹爪规格；不需要新物体的成功示范 |
| 输出 | 逐点抓取频率、多抓法覆盖分数、筛选后的区域点云 |
| 标签 | 实际接触区域 + 有限夹持空间内的物体表面；每次抓取只计一次 |
| 核心验证 | 已见物体、多抓法、外观变化、同类未见几何实例 |
| 边界 | 只预测观测到的表面；分数描述示范支持，不等于物理抓取成功概率 |

保留 v1 的同步 RGB-D、物体坐标系标签、PointNet++ 和冻结 DINO。改为物体级采样、频率/覆盖双头、资产级测试及逐阶段验收。允许自动实例定位参与推理，替代 v1“实例信息仅用于离线”的约束；用户无需手工分割视频。

旧结果仅作技术记录：一个 alphabet-soup 资产、47 次未复核候选事件、8 epoch 试跑；16k 全场景采样时目标物体验证集中位仅 215.5 点。旧检查点和接触点高斯标签不能充当 v2 的验收结果。已分析或展示的旧测试样本仅作开发对照，v2 正式测试另留未参与设计/调参的数据。

## 2. 数据与划分

先做圆柱体/罐体和带柄杯子。圆柱体覆盖半径、高度、颜色变化；杯子覆盖杯身、杯柄、杯口等**确实成功的**抓法。某实例不可行的抓法不强行标正。

- 小试：每类 3–5 个实例；每个实例的每种适用抓法初始收集至少 10 次独立成功事件。
- 扩展：每类初始 20/5/5 个训练/验证/测试几何实例；规模不足则补数据，不以大量相邻帧替代实例。后续依据训练/验证学习曲线扩展，测试集保持封存。
- LIBERO 不足的实例及抓法在仿真中补充。换色可复用几何标签；改尺寸或形状后必须重新执行并验证抓取。
- 按事件记录物体、几何资产、尺寸、任务、抓法、episode、成功判据及质量。保持抓法采集配额明确；频率解释为该采集分布下的频率。

| 协议 | 分组规则 | 回答的问题 |
|---|---|---|
| 已见物体 | 同一资产按完整 episode 分 70%/15%/15% | 学过的区域在新观测中是否正确 |
| 外观变化 | 独立测试 episode 中固定几何/相机，仅改颜色纹理 | 是否依赖颜色捷径 |
| 同类新实例 | 按几何实例分组；同网格、尺寸及其换色衍生数据同组 | 是否迁移到未见尺寸/形状 |
| 尺寸外推 | 另留超出训练尺寸范围的实例 | 范围外是否仍有效；单独报告 |

参数化圆柱按独立尺寸组合分组，不以随机种子或纹理作为“新几何”。杯子增加不同杯柄/杯身网格；记录母资产及衍生关系，近重复资产不得跨组。每个协议先划分，再用各自的成功事件建立标签库；训练不得读取验证/测试接触。测试标签仅供最终评分。

## 3. 成功事件与区域标签

### 3.1 同步观测和成功判据

恢复同一仿真状态后同时渲染 RGB、米制深度、离线实例掩码；相机为 agentview 与 robot0_eye_in_hand，分辨率 448×448，保存逐帧内外参及像素—点对应。

成功候选初始条件：同物体双指接触至少 3 帧，随后抬升至少 5 cm，夹持阶段物体相对夹爪位置漂移不超过 3 cm；另外检查相对转动、持续保持及搬运是否稳定。阈值在阶段 0/1 的开发事件上确认并冻结。擦碰、推动、掉落和无法确认的事件不作为正例，也不直接当负例。

### 3.2 单次事件掩码

将物体表面及接触变换到物体自身坐标。对稳定夹持阶段定义：

1. **接触区 C**：实际指垫—物体接触在视觉表面的局部投影。投影误差过大或归属不明则标为不确定，不能扩大半径掩盖错位。
2. **包裹区 E**：物体表面与两指内侧形成的有限空间相交。闭合方向由两指内侧面限定；另外两轴由真实指垫的有效长度、高度限定。使用实际关节开度与夹爪几何，不能用整只夹爪的大包围盒代替。
3. **事件标签 m_e**：接触区与包裹区的并集。对一个稳定短时间窗的掩码按逐点多数投票汇总；不累计接近、搬运全轨迹的扫过空间。保留接触/包裹两个分量供检查。

包裹区是本研究约定的几何区域，不宣称其中所有表面都有接触力。必须抽查杯柄孔洞、邻近杯身和指尖边界，确认没有包入无关表面；只标目标物体表面，不生成空气或内部体积点。边界不确定点设 valid=0；边界容差由开发集确定并记录。

### 3.3 汇总两套监督

对同一几何实例、同一数据划分内 N 个合格成功事件：

- 频率：y_freq(x) = sum_e m_e(x) / N。
- 覆盖：y_cover(x) = max_e m_e(x)。

保留每个事件和抓法的独立掩码，不把不同抓法坐标平均；一次夹取的左右接触斑属于同一抓法。不同几何实例各自建标签，靠网络学习迁移，不直接坐标叠加。

频率标签使用所有合格事件的真实计数；为照顾少见抓法而做的重采样不能改变这套标签。采集未覆盖的位置只表示“未被这些示范支持”，不能解释为不可抓。训练表面标签可由仿真完整几何建立，网络输入仍仅来自抓取前可见 RGB-D。

## 4. 网络设计

### 4.1 完整流程

```text
完整示范 + 动作/状态 → 成功事件 → 接触/包裹掩码 → 频率、覆盖标签（离线）

当前两路 RGB-D
  ├─ 自动实例定位 → 每物体可见点云 → 几何特征 ─┐
  └─ RGB → 可选冻结 DINOv2 → 逐点视觉特征 ───┤
                                              ↓
                                    PointNet++ 共享骨干
                                      ├─ 频率头 → 每点频率
                                      └─ 覆盖头 → 每点区域分数
                                              ↓
                                   世界坐标点云 + 分数 + 图例
```

**定位网络**：Mask R-CNN，ResNet-50 + FPN，RPN + RoIAlign，检测/框回归/实例掩码三分支；仅设“可操作物体”一个前景类别，桌面和机器人为背景。用训练划分的仿真实例掩码监督，损失采用 RPN、分类、框回归、掩码损失之和；预训练权重及版本固定记录。初始 AdamW、学习率 1e-4、batch 4、最多 50 epoch，验证 mask AP 连续 10 轮无改善早停。

两相机掩码反投影后，按深度一致性、重叠表面和一对一几何匹配合并；不确定匹配保留独立候选并计入错误，不用真实实例 ID 消歧。定位置信度、NMS 和跨视角阈值只用验证集选择。

阶段 2–5 先用真实掩码隔离检验区域学习，并明确标为“理想定位条件”。阶段 6 必须替换为预测掩码，报告完整系统；真实位姿、资产 ID、接触及未来动作不得进入推理。

### 4.2 物体输入

每个物体默认 N=4,096 点，先空间去重再采样；不足时填充并使用有效点掩码；采样、池化、插值、损失和评估均排除填充点，不把重复点当新增信息。记录真实点数、覆盖和稀疏失败。采样不读取抓取标签。

令 c 为观测点质心，s 为到质心距离的 95% 分位数（下限 1 mm），p_m=p-c，q=p_m/s。q 用于邻域查询；p_m 和 s 保留米制尺寸。s 是观测尺度，不是仿真真实完整尺寸；不输入真实物体姿态或类别 ID。

| 特征 | 维度/映射 |
|---|---|
| 几何 | [p_m(3), s, s/w_max, w_max, 指垫有效长, 指垫有效高]，8→32 |
| RGB 对照 | 每点 RGB，3→32；与几何拼接 |
| DINO 对照 | 冻结 DINOv2 ViT-S/14；448 图像得到 32×32 patch 特征，按像素插值取 384 维，384→64 |
| 融合 | 几何/RGB/DINO 对应拼接维度 32/64/96，经 Linear→64 + ReLU |

w_max 是已知夹爪最大开口。不同变体均使用相同采样、划分、骨干和双头。RGB/DINO 按点对应像素取特征，不用全图单个向量。两视角同一点的特征平均或按深度可靠性加权，规则在配置中固定。

### 4.3 PointNet++ 与双头

B 是批大小，N=4,096；所有半径均在归一化 q 坐标中定义，不能与 v1 的米制半径混用。MLP 使用 ReLU，邻域共享 MLP 后最大池化；特征传播采用三近邻插值和跳跃连接。

| 模块 | 输出尺寸 | 初始结构 |
|---|---|---|
| 输入投影 | B×4096×64 | 上述融合特征 |
| SA1 | B×1024×128 | FPS；半径 0.10；32 邻点；MLP 64→64→128 |
| SA2 | B×256×256 | FPS；半径 0.20；32 邻点；MLP 128→128→256 |
| SA3 | B×64×512 | FPS；半径 0.40；32 邻点；MLP 256→256→512 |
| FP3 | B×256×256 | 插值+SA2 跳连；MLP 256→256 |
| FP2 | B×1024×128 | 插值+SA1 跳连；MLP 256→128 |
| FP1 | B×4096×128 | 插值+输入跳连；MLP 128→128 |
| 频率头 | B×4096×1 | 独立 MLP 128→64→1 |
| 覆盖头 | B×4096×1 | 独立 MLP 128→64→1 |

SA 中同时使用相对 q 坐标；表中 MLP 数字表示输出通道，首层输入为邻点特征与相对坐标的拼接。两个头训练输出 logits，推理各自 Sigmoid，不能对所有点做 Softmax。覆盖图允许多个不连通区域；它不直接输出抓法编号或夹爪姿态，抓法身份保留在监督和分项评估中。

## 5. 损失、训练与对照

- L_freq：对 y_freq 的软标签 BCEWithLogits；不使用正例加权，以免人为改变频率含义。
- L_cover：对 y_cover 的 BCEWithLogits + 0.5×SoftDice，保留多区域。
- L = L_freq + L_cover。每个物体先对有效表面点平均，再对物体平均；空掩码跳过。无标签物体不直接当不可抓负例。
- 采样按物体等权，再按事件等权；同事件多帧不能增加事件权重。区域训练使用起始帧和接触前约 0.5/1/1.5 秒的合格帧，不输入接触后的夹爪状态。
- 区域网络初始 AdamW，lr=1e-4，weight_decay=1e-4，batch=8（显存不足降批量），最多 100 epoch，验证覆盖区域 mIoU 连续 15 轮无改善早停；并列时用频率 MAE 选优。DINO 冻结，记录随机种子 0/1/2。
- 增强包含观测旋转、轻微深度噪声、丢点、颜色变化；坐标和标签同步变换，改变图像后重算 DINO。改变物理尺寸须重验抓取，不做未经验证的几何缩放标签增强。
- 先分别训练定位与区域模块；完整流程验证前，再用训练集预测掩码/扰动掩码训练区域网络适应定位误差，并单列该结果。

对照依次为：随机选区、按物体高度/径向位置统计的训练集几何先验、几何 PointNet++、几何+RGB PointNet++、几何+DINO PointNet++、几何+DINO 逐点 MLP（不用邻域聚合）。逐点 MLP 为输入→256→128→128，再接相同双头。另做“接触标签 vs 接触+包裹标签”消融，按相同新标签评价。

## 6. 评价定义与分阶段验收

**指标统一口径**：在独立示范支持的可见表面上计算。Region IoU 比较阈值化覆盖图与参考覆盖并集；Mode Recall 分别计算每种抓法掩码被预测区域覆盖的比例；频率 MAE 衡量预测与独立事件频率的差。主结果对物体等权，再按类别/抓法报告，禁止仅汇总相邻帧。

使用仿真可见网格的均匀表面积采样作离线评价基准，将预测仅映射到深度支持的表面；同时报告可见比例、映射有效比例和采样上限。映射失败的可见区域按漏检处理，不能排除后抬高成绩。固定点数预算 10/20/30% 的接触覆盖率作为辅助，不能冒充表面积或抓取成功率。

正式阈值 τ 在验证集选择一次并冻结；区域面积比 A_pred/A_ref 一并报告，防止整物体涂亮。训练集拟合检查固定 τ=0.5。置信区间以实例为重采样单位；已见物体协议以 episode 为单位。无可见正区域时召回记 NA，另报误报，不记满分。

**以下数值是工程验收起点，不是统计功效保证。阶段 0 冻结；不得看完测试后降低门槛。** 若采样精度或任务范围需调整，升版并重新划分/验收。每阶段保存证据和 PASS/FAIL/PENDING；上阶段未通过，不进入下一阶段扩大训练。

| 阶段 | 工作与交付 | 通过条件 |
|---|---|---|
| 0：冻结范围 | 资产/抓法清单、夹爪规格、划分、配置、指标与阈值 | 两类数据的获取路线明确；每种目标抓法有成功实例；无资产/episode 泄漏；缺口列清，不能以单资产代替泛化 |
| 1：观测与标签 | 10 条恢复审计；接触/包裹三维对照；分层抽查 30 事件 | 10/10 同步恢复正确；独立轮廓投影中位误差≤2像素且无系统错位；至少27/30事件归属、成功和包裹边界正确；发现的错误修复/剔除，系统性错误必须重审 |
| 2：样本就绪 | 小试实例库、事件级标签、样本与可见性报告 | 每类3–5实例、每实例适用抓法各≥10事件；标签库与输入无泄漏；开发/验证集至少95%视图的可见标签表面采样覆盖≥95%（距离容差冻结并记录）；稀疏/遮挡失败不静默丢弃 |
| 3：小样本拟合 | 覆盖两类与全部已声明抓法的20个样本；训练曲线及逐例图 | 关闭增强，训练 Region IoU≥0.90、频率MAE≤0.05、各抓法Recall≥0.90；失败先查标签/实现，不扩大训练 |
| 4：已见物体 | 新episode/新视角结果、全部对照、3种子 | 每类测试 mIoU≥0.65；各抓法平均Recall≥0.70；平均面积比≤1.5；频率MAE比训练集常数频率先验至少降低20% |
| 5：同类新实例 | 每类初始20/5/5实例划分；外观/尺寸/形状分别评估 | 新几何每类mIoU≥0.50，较随机/几何先验中较强者提高≥0.05；各抓法Recall≥0.60，平均面积比≤1.5；只换色时对应表面两头预测MAE均≤0.05；外推单列 |
| 6：完整输入验收 | 原始RGB-D→预测实例→区域点云；三种子与漏检/误报表 | 不读取真实实例/位姿/未来动作；每类区域mIoU相对理想定位下降≤0.10；漏检物体计零、重复候选计误报；展示已见、换色、新尺寸、新网格及失败样例 |

阶段 4–6 门槛按三种子均值检查，同时公开每种子、每实例结果及波动，不能只挑最好一次。阶段 5 的频率 MAE 须比常数先验降低至少20%；若覆盖通过而频率未达标，只能结论为区域迁移，不能宣布频率学习完成。无法观察的抓法单列可见性限制，不据 NA 宣称多抓法通过。

人工复核只针对成功事件、物体归属、接触/包裹边界及代表抓法，不要求逐帧手工标整套数据。阶段 1 的复核须记录检查者和结论，不能把自动检查或几张预测图当作已人工验收。

最终每例导出 object_points.ply、frequency.ply、coverage_regions.ply、scores.npz 和 overlay.png。图用统一0–1色条、中文图例，并排展示输入/参考区域/预测；接触、包裹、频率、覆盖分别展示，不混用颜色含义。三维图可旋转，包含盲抽样例与失败例，不能只展示最好结果。

本文件描述待实施设计；后续按阶段建立具体脚本和运行命令，不把尚不存在的脚本写成已经可执行。旧4k/16k结果不进入新方案验收。
